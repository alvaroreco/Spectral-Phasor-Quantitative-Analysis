## Overview

This repository contains Python code for the analysis of fluorescence emission spectra using spectral phasor methods. The code allows fluorescence spectra to be transformed into spectral phasor coordinates and provides tools for visualizing phasor trajectories and performing quantitative analyses of reversible protein denaturation.

The implementation was developed to analyze spectral changes associated with protein unfolding and to extract thermodynamic information from the resulting spectral phasor trajectories. The repository includes the code used for the analyses presented in the associated publication.

## Citation

Recoulat Angelini AA, Malacrida L, González Flecha FL. Linear combination properties of spectral phasors allow thermodynamic analysis of reversible denaturation of multidomain and membrane proteins. Int. J. Mol. Sci. 2026.
